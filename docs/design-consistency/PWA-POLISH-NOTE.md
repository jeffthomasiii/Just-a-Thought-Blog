# PWA Integration Polish — September 2026

The installed Just A Thought PWA uses a shared hero language across Home, Explore, Listen, and More: warm editorial imagery, cream-to-transparent overlay, left-aligned Playfair display copy, and restrained olive accents. Individual pages retain distinct imagery and content while sharing composition.

Android installed-app browser narration uses short sequential SpeechSynthesis utterances as a compatibility fallback. Desktop/browser narration retains the existing implementation. This avoids replacing the site's audio system while reducing the long-utterance failures seen on some mobile speech engines.
